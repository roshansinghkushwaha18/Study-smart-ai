About StudySmart AI

Developed for university coursework in BBA Digital Marketing & Artificial Intelligence.

Academic Context

StudySmart AI was conceptualized to address real workflow challenges university students experience when studying multidisciplinary subjects like Digital Marketing (SEO, SEM, Social Media, Google Ads, Analytics) and Artificial Intelligence & Machine Learning.

It combines server-side AI reasoning via OpenAI with client-side zero-database privacy through browser LocalStorage.

Technology Architecture

  • Frontend: Semantic HTML5, CSS3 Glassmorphism, Vanilla JavaScript (ES6 Modules)
  • Backend Server: Node.js, Express.js with CORS, Dotenv, and Request Sanitization
  • AI Engine: Official OpenAI JavaScript SDK (Configurable Model: gpt-4o-mini)
  • Persistence: Resilient LocalStorage wrapper with corrupted JSON auto-recovery
  • Audio: Web Audio Synthesizer API for lightweight, zero-dependency focus chimes

Security & Ethics Notice

API Key Privacy: All API keys remain strictly on the backend server and are never exposed to client browsers.

Academic Integrity: The platform is designed to provide guided explanations, formulas, and frameworks to stimulate understanding rather than enabling blind copying.
